Ultima I engine - portable Windows build (x86-64)
=================================================

No installer and no administrator rights are needed.

1. Extract this ZIP anywhere you can write to (Desktop, Documents, a USB stick).
   Do not run it from inside the ZIP, and avoid C:\Program Files.
2. Copy the files of YOUR OWN copy of Ultima I into the ULTIMA1 folder here
   (OUT.EXE, MAP.BIN, TCD.BIN, ULTIMA.EXE, GEN.EXE, the tiles such as
   EGATILES.BIN + EGATOWN.BIN, and the rest of the game's files).
   No game files are included in this download.
3. Double-click ultima1-engine.exe.

Everything the engine writes stays in this folder:
  config.toml   options chosen in the F1 menu
  saves\        your characters and save slots (copies; the game files in
                ULTIMA1 are only ever read, never changed)
To move or back up your game, move or copy the whole folder.
Deleting portable.txt makes the program use the normal per-user folders instead.

F1 opens the options; PLAYING.md explains the keys and every option.
If the game files are missing, a window lists the folders searched.

Windows may warn that the program is from an unknown publisher, because it is
not code-signed. Choose "More info" and "Run anyway" if you trust this copy.
